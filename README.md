### Lab Activity List
**Lab 1 - Theme(Dark/Light Mode)**: setState is used for managing local widget state, such as the counter value, and only rebuilds the widget where the state changes. Provider manages shared application state, such as the app theme, by allowing multiple widgets to access and update the same data. In this code, setState is suitable for the counter, while Provider is better for the theme because it affects the entire application.
